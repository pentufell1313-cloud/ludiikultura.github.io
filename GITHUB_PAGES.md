# Публикация карты на GitHub Pages

## Структура репозитория

Файл `index.html` должен находиться в корне репозитория, а папка `assets` — рядом с ним:

- `index.html`
- `assets/`
- `sources.txt`
- `README.md`
- `.nojekyll`

Фотографии из исходного архива проекта подключены **относительными путями** вида `assets/image_....jpeg`. Поэтому они будут загружаться с того же GitHub Pages-сайта и не зависят от файловой системы компьютера автора.

## Публикация

1. Создайте публичный репозиторий на GitHub.
2. Загрузите **содержимое этой папки**, а не сам ZIP-файл.
3. Проверьте, что `index.html` находится именно в корне репозитория.
4. Откройте Settings → Pages.
5. В Build and deployment выберите Deploy from a branch.
6. Выберите `main` и `/ (root)` и нажмите Save.
7. После публикации GitHub Pages даст адрес вида:
   `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`

## Почему фотографии теперь будут работать

Ранее архив содержал дополнительную папку `mirny_final2/`. Если её загружать как отдельную папку в репозиторий, GitHub Pages может не найти `index.html` как корневой файл сайта. В этой версии `index.html` и `assets/` находятся на одном уровне.

Также изображения из исходного архива не требуют `file:///`, абсолютных путей Windows или локальных адресов: все они подключены относительными URL.
