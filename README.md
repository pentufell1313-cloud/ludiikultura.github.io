# Мирнинский район — интерактивная краеведческая карта

Финальная конкурсная версия цифрового краеведческого проекта.

## Что внутри
- интерактивная карта на MapLibre GL JS;
- картографическая основа OpenFreeMap / OpenStreetMap;
- официальный по правовому статусу муниципального района контур: правовая основа — Закон Республики Саха (Якутия) №172-З №351-III «Об установлении границ и о наделении статусом муниципального района…» с последующими изменениями;
- геометрия границы загружается из пространственного слоя муниципальных образований Центра геоданных НИУ ВШЭ (Yakutia_economics_February_2026_MIL1), где доступен GeoJSON через ArcGIS REST;
- 28 тематических объектов из материалов архива проекта;
- фотографии из предоставленного архива, встроенные в кликабельные маркеры и карточки;
- поиск и фильтры;
- подробные всплывающие карточки;
- кнопка «Весь район» и переключатель отображения границы;
- адаптация для компьютера и телефона.

## Важное уточнение о границе
Граница муниципального района имеет правовую основу в региональном законе. Веб-карта использует пространственную геометрию открытого геоданных-слоя ВШЭ, а не самодельный полигон. Поэтому в интерфейсе она обозначена как граница Мирнинского муниципального района, а в README отдельно указаны и правовой источник, и источник геометрии.
